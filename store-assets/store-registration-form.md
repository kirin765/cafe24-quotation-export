# 카페24 스토어 상품 등록 — 필드별 입력값

등록 폼 순서대로 적었다. `[이미지]`는 저장소 파일 경로, `[확인 필요]`는 사용자 확인이 있어야 확정할 수 있는 항목이다.
글자 수/바이트는 UTF-8 기준으로 세었다.


**마케팅 문구** (3개 이상, 각 1~200 bytes — 아래는 5개)

```
카페24 상품·옵션을 검색해 견적 품목으로 바로 가져옵니다
같은 내용을 편집 가능한 XLSX와 A4 인쇄용 PDF로 내보냅니다
확정한 견적은 그 시점 그대로 남고, 이후 수정은 새 버전으로 쌓입니다
CSV·엑셀 파일로 품목을 한 번에 올리고, 오류는 행 번호로 알려 줍니다
견적서는 주문 전 제안이며 결제·주문으로 표시하지 않습니다
```

**상세 설명 본문**

- HTML 방식: `store-assets/detail-description.html` 내용을 그대로 붙여 넣는다(이미지 5장, alt 텍스트 포함, 폭 1240px 이하).
- 이미지 URL은 `https://cafe24-quotation-export.vercel.app/store/detail-01.png` ~ `detail-05.png` (배포본에서 서빙).
- 편집기 방식으로 넣을 경우 같은 이미지 파일을 `public/store/`에서 올린다.

**FAQ** (폼에서 하나씩 입력하거나, 폼의 양식 CSV를 내려받아 옮긴다)

| 질문 | 답변 |
|---|---|
| 견적서를 파일로 받을 수 있나요? | 네. 같은 내용을 편집 가능한 XLSX와 A4 인쇄용 PDF로 내보냅니다. PDF는 인쇄 화면에서 브라우저의 ‘PDF로 저장’을 사용합니다. |
| 상품을 일일이 입력해야 하나요? | 아니요. 쇼핑몰 상품을 검색해 담거나, 이미 쓰던 CSV·엑셀 파일을 그대로 올릴 수 있습니다. |
| 엑셀에서 수량을 고치면 합계도 바뀌나요? | XLSX는 숫자 값을 담고 수식은 넣지 않습니다. 자동 재계산되지 않는다는 안내를 파일 안에 표시하며, 재계산이 필요하면 앱에서 고친 뒤 다시 내보내면 됩니다. |
| 부가세도 계산해 주나요? | 자동 계산하지 않습니다. ‘가격 조건’에 세금 포함 여부를 적어 두고, 필요하면 조정 금액으로 더합니다. |
| 앱 설치 후 바로 쓸 수 있나요? | 카페24 관리자에서 앱을 실행하면 상품 조회 권한에 동의한 뒤 바로 견적 목록이 열립니다. |
| 어떤 권한을 요청하나요? | 상품 조회(mall.read_product)와 앱 설치 정보뿐입니다. 주문·회원 정보는 조회하지 않습니다. |
| 확정한 견적을 고치면 어떻게 되나요? | 확정본은 바뀌지 않고, 수정한 내용은 다시 확정할 때 새 버전으로 쌓입니다. |
| 앱을 삭제하면 데이터는 어떻게 되나요? | 저장된 카페24 접근 토큰을 바로 삭제합니다. 만든 견적은 몰별로 보관되며 다시 설치하면 그대로 보입니다. |
